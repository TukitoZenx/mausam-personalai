# Mausam PersonalAI Screenshots Directory

Replace the files in this directory with real high-resolution screenshots captured from the Flutter mobile app (Android or iOS):

| Filename | Description | Recommended Source Screen in Flutter App |
| :--- | :--- | :--- |
| `hero.png` | Main hero visual / showcase | `HomeScreen` with current weather & atmospheric gradient |
| `home.png` | Live home feed & temperature | `HomeScreen` with 7-day forecast & active persona card |
| `insights.png` | Adaptive recommendation feed | `InsightsScreen` with outdoor window, commute, or AQI card |
| `weather-ai.png` | Mausam Weather AI interaction | `ChatScreen` with weather queries & reasoning |

### Aspect Ratio & Dimensions
- Recommended resolution: `1080 x 2400` px (standard 20:9 phone screen) or `1170 x 2532` px (iPhone).
- Format: PNG with lossless compression.
- Until real PNGs are saved here, the landing page uses built-in obsidian SVG UI frames that preview each screen's layout cleanly.
